# v1.0.0 — Windows x64

First public release of the Chihiro libretro core and ChihiroPack XBE-package-to-BIN converter. Maintainer testing passed on nine game profiles: Virtua Cop 3, The House of the Dead 3, Ghost Squad, OutRun 2, OutRun 2 Special Tours, Maximum Tune 1/2 Export, Crazy Taxi High Roller and Ollie King. Coverage is specific to recognized revisions.

**Vulkan is strongly recommended. Start a fresh RetroArch process for each game.** Gun and steering calibration are required. Optional widescreen profiles, crosshair sizing, game-specific input descriptions and supported card saves are included. Some menus stretch and HUD elements retain 4:3 placement. Sega Golf 2006 is not recommended as established playable.

Use normal gamepad/XInput controls for driving/board games or Wiimotes via Lichtknarre/vJoy with the included optional dinput profile for guns. Disable Left Analog in Menu for IR input. Standalone RetroArch is the primary setup; RetroBat integration is optional. No commercial games or Chihiro/Xbox BIOS are included.

Download **Chihiro_Libretro_v1.0.0_Windows_x64.zip** for the core and runnable converter. Download **Chihiro_Libretro_v1.0.0_Source.zip** for complete modified core/converter source, patches, build/test material, dependencies and notices. Verify both with **Chihiro_Libretro_v1.0.0_SHA256SUMS.txt**. GitHub's automatic Source code ZIP contains the smaller repository tree, not all emulator sources.

Accepted core and converter binaries are unchanged. Packaging/source checks passed; no fresh Windows rebuild or universal compatibility certification is claimed.
